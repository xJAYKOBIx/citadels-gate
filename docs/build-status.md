## How to test
- Three.js can't load in the cloud sandbox (all CDNs/npm blocked). 3D is checked in the user's in-app browser pane on the published artifact: navigate to `claude.ai/code/artifacts` first, then to the artifact URL with a hash (the hash is only read on a fresh load); wait ~20 s; screenshots work. `resize_window` 390×844 / 844×390 emulates a phone (reset to desktop after). The frame is cross-origin, so no JS/console access — a red error strip in the page is the only runtime-error signal.
- Hash tokens combine with `-`: `#sylvan` / `#frostmere` / `#pass` (switch map, reloads), `#lab`, `#battle`, `#fast` (4×), `#fx`, `#plain`, `#diag`, `#at<x>.<y>.<dist>.<yawdeg>.<tiltdeg>`, `#tour`, `#tour2`, `#phone` / `#desktop` (force touch camera + compact HUD on/off).
- Headless tests in `/home/claude/cg/t` (recreate; they don't persist): `sim.js <file> <diff> <n> [map]` (AI-vs-AI via `FA.simulate({diff})`; before v11 it passed `difficulty:` so earlier "veteran" sims were regular); `dom.js <file> <hash> [w h]`; `hud.js <file> <w> <h> <out.png>` (touch phone viewport, starts a battle, selects a unit, reports HUD rects and screenshots the 2D HUD — the best way to check layout headlessly); `chk.js <file> <map>`; `probe.js <file> <map> "<expr>"` (`FA.eval`); `stub3d.js` (unreliable, hangs); map previews `gen2.js`, `render_map.py`, `render_3d.py`. v13 adds `pairs.js <file> <map> <n-per-side> cmdA,cmdB ...` (commander pairings, both sides, JSON lines; env `PRE` = expression run once via `FA.eval`), `agg.py` (pairing table), `duel.js <file> A:B ...` (equal-gold fights in the North Glade, env `G` gold), `gate.js`/`gate2.js` (gate exits), `cache.js` (scout time to every cache per team — the side-bias check), `menu.js <file> <w> <h> <png> [hash]`, `drop.js` (player tap flow), `walk.js <file> <map>` (gate → every overlook/cache/plateau).
- In-app browser: when the pane is hidden the page's animation loop is paused (clock stays 0:00), so only static frames can be checked.

## v15 — nests, keep walls, Rank I start, mage as the core mortar
- **Hilltop drops**: the real causes were in `planDrop`: a tap within `laneHitR()` of a lane snapped the goal onto the lane even for support units (every overlook is within that radius), and `snapOpen` picked the nearest open cell regardless of height. Now support/stationary units never lane-snap; `snapLevel()` prefers open cells within 1.5×`MAP.step` of the tapped ground height; casters/stationary units tapped within max(nest.r, laneHitR) of a nest go to the nest centre (`nestAt`, `NESTS` from `MAP.nests`, plan.nest, a `nest` toast). `s2w` ray-march from v14 stays. Headless `t/drop.js <file> <type> <x> <y>` runs the player's exact tap flow.

## v12 — mobile HUD, touch input, droppable hidden paths, lighter forests
- **Touch input** (mouse unchanged): a drag starting on a unit that isn't selected pans the map. To draw a path: tap the unit (selects it), then press and hold it `DRAW_HOLD` 170 ms (gold ring fills, a vibrate tick) and drag; moving before the hold completes is a pan. Same for extending a path from its end dot (22 px). Gesture type `'pend'`, `pendToDraw()`, a 40 ms interval promotes a resting finger. While a finger draws, the sim runs at `CONFIG.drawSlow` 0.33. Quick release on the selected unit is a tap.
- **Compact HUD** (`html.compact` when `TOUCHUI` or min(W,H) < 560; `html.port`; `html.side` = compact + landscape), set in `layout()`:
  - Top strip ≈31 px: just the two keep bars with numbers and the clock; names/ward words hidden; ward shown as a gold outline on the bar (`.bar.warded`), exposed keep pulses red (`.bar.exposed`).
  - Cards: icon + cost only (names on long-press pop-over as before), 42 px tall. Portrait: two rows of 7 (tray 103 px vs 137). Landscape: a two-column tray down the right edge (`--trayTop`), `view.w = W − tray width`, so the field keeps its full height (844×390: field 723×359 vs 844×272 before).
  - Unit chip: one slim pill above the tray — short name, hp, status — with icon buttons (march arrow, hold square, ✕); fades after `CHIP_FADE` 4.5 s (tap the unit again to bring it back; `S.selAt`). Selection hint shows only for 3 s. Toasts sit beside the minimap at the top; shorter first-deploy toast on touch.
  - Minimap smaller in compact; `#miniTog` button collapses/expands it (remembered in `localStorage` `cc-mini`; `MINI_COLLAPSED`, `toggleMini()`).
  - Measured headless at 390×844: field 390×644 → 390×710; at 844×390: 844×272 → 723×359.
- **Hidden paths droppable** (`MAP.hiddenPaths` names → `HIDDEN[i].byTeam[t]` thinned polylines oriented from each side; `hiddenAt()`; `planDrop` mode `'hidden'` for fighters, ground only, after the lane check): the unit sets out from the base edge nearest the path start, follows the whole path through the Hidden Ford, then `autoLane` joins the far lane and marches it (tested: Warder dropped on the Elder path reaches (2097,1465) and joins lane 1).
